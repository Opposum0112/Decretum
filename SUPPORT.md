# Support

For questions and design discussion:

- Open a GitHub Discussion when discussions are enabled.
- Open an issue for a reproducible bug or concrete feature request.
- For security issues, follow [SECURITY.md](SECURITY.md).

When asking for help, include the Decretum version/commit, Python version, operating system, command used, and a minimal reproducible example where possible.

# Support

## Bugs and feature requests

Please use the public GitHub issue tracker for reproducible bugs and feature requests.
