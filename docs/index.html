The model

Semantic intent. Deterministic handoff.

Knowledge and specifications define meaning. Decretum compiles that intent into a concrete execution boundary. Agents and harnesses own reasoning and execution.

01 / SCHEMA

What is possible

LinkML defines roles, skills, capabilities, evidence and references as reusable research vocabulary.

02 / RECIPE

What is allowed

A recipe declares the investigation's required capabilities, constraints and execution boundary.

03 / CONTRACT

What is frozen

Validation and compilation turn the recipe into a machine-readable research contract.

04 / AGENT

How to investigate

The autonomous researcher selects and composes declared skills instead of silently expanding scope.

05 / PROVIDERS

How capabilities run

MCP, APIs and local tools can implement the same semantic capability interchangeably.

06 / STATE

What survives

Evidence, hypotheses, findings, experiments and reports remain available for continued research.

Execution loop

From intent to execution.

“Specification defines meaning · Recipe declares intent · Decretum resolves execution · Contract freezes the handoff.”

A capability can evolve independently of its implementation. New providers, integrations and model families can be registered without changing the meaning of existing recipes.
