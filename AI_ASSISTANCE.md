# AI-Assisted Development

## Purpose

Decretum uses AI assistance as an engineering tool. This document records that use so repository visitors can distinguish **human project ownership** from **AI-assisted implementation**.

## AI contributor

**ChatGPT (OpenAI)** may assist with:

- architecture and design exploration
- implementation and refactoring
- code review and debugging
- test development and troubleshooting
- documentation
- repository maintenance and Git workflows

## Human responsibility

Vignesh Kumar remains the project owner and maintainer. Human review and acceptance are required for changes that become part of the project's maintained history or releases.

AI-generated suggestions are not treated as authoritative merely because they were generated by an AI system.

## Git attribution

GitHub supports multiple authors through `Co-authored-by` trailers, but GitHub requires a co-author identity and associated email address for contribution attribution. Decretum will **not invent or impersonate a GitHub identity for ChatGPT**.

Consequently:

1. Repository documentation identifies ChatGPT as an AI-assisted contributor.
2. Pull requests may explicitly state when AI assistance was used.
3. Commit messages may mention AI assistance when useful for provenance.
4. A real GitHub account or GitHub App may only be used as an AI contributor if it is separately created and legitimately controlled for that purpose.

This keeps the contributor record accurate rather than manufacturing contribution statistics.

## Transparency principle

The goal is to make AI involvement visible without overstating the autonomy, ownership, or authorship of the AI system.

For details on GitHub's supported co-author mechanism, see the GitHub documentation on [commits with multiple authors](https://docs.github.com/en/pull-requests/how-tos/commit-changes/creating-a-commit-with-multiple-authors).
